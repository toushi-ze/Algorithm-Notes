# 141. 环形链表 (Linked List Cycle)

> **📅 日期**：2026-03-22
> **💡 难度**：🟢 简单
> **🏷️ 考点**：双指针、快慢指针

---

## 1. 题目介绍
* **题目链接**：[LeetCode 141. Linked List Cycle](https://leetcode.cn/problems/linked-list-cycle/)
* **核心目标**：给定一个链表的头节点 `head`，判断链表中是否有环。
* **逻辑定义**：如果链表中有某个节点，可以通过连续跟踪 `next` 指针再次到达，则链表中存在环。为了表示特定链表中的环，评测系统内部使用整数 `pos` 来表示链表尾连接到链表中的位置（索引从 0 开始）。注意：`pos` 不作为参数传递。

---

## 2. 解题思路

### 🚀 优化思路：快慢指针 (Floyd's Cycle-Finding Algorithm)
* **核心逻辑**：速度快的fast终究会超过速度慢的slow并完成套圈
* **复杂度分析**：
    * **时间复杂度**：$O(n)$
    * **空间复杂度**：$O(1)$



### 📊 指针全景表

| 指针变量 | 类别 | 初始位置 | 移动步长 | 核心使命 |
| :--- | :--- | :--- | :--- | :--- |
| **`slow`** | **追击** | `head` | 1 步 | 稳步前进 |
| **`fast`** | **探测** | `head` | 2 步 | 快速前进，若有环负责相遇 |

---

## 3. 总结

> **总结：** 双指针不仅可以用来保持固定距离（如 LC19），还可以通过速度差来探测链表

| 关注 | 分析 |
| :--- | :--- |
| **为什么是 2 步** | 2 步与 1 步的相对速度为 1，环内，两者的距离每步缩小 1，因此会相遇而不会跳过 |
| **边界防御** | 在访问 `fast->next->next` 之前，确保 `fast` 和 `fast->next` 都不为 `NULL` |
| **代码规范** | 先进行入参检查 `if (!head)`，再进行指针初始化 |
